# gemini
Contiene información sobre la temas relacionados con Google Gemini

- [Promps del Taller del DevFest 2025](devfest2025/prompts.md): Colección de prompts del taller "Tu Genio Personal", que incluye ejemplos para crear tutores de programación y simuladores de entrevistas técnicas.
- [Asistente para Casos de Prueba](testCases/prompts/asistente.md): Prompt especializado para generar casos de prueba detallados (Happy Path, Negative, Edge Cases) siguiendo estándares de QA.
- [Spec-Driven Development (SDD) con IA (GDG Cuenta)](spec-driven-development/workshop-gdg-cuenca.md): Diseñar software para *Registro de Estudiantes* asistido por IA utilizando especificaciones como fuente única de verdad (*Single Source of Truth*) usando Antigravity.
- [Spec-Driven Development (SDD) con IA (CS IEEE)](spec-driven-development/workshop-csieee.md): Diseñar software para *Venta de Autos* asistido por IA utilizando especificaciones como fuente única de verdad (*Single Source of Truth*) usando Antigravity.
